### [Peter's World](https://www.peters-world.com/) - Living Ecosystem Simulation
A performance-optimized 3D web application demonstrating advanced React Three Fiber usage.

**Key Features:**
- **Complex Systems Architecture**: Autonomous animal behaviors using state machines, terrain deformation, selective physics simulation supporting 50+ concurrent entities at 60fps
- **Performance Engineering**: Zustand state management preventing cascading re-renders, Rapier.js physics optimization, mobile-responsive 3D rendering
- **Interactive Design**: Real-time terraforming tools, dynamic ecosystem evolution, physics-based environmental interactions
- **Technical Innovation**: Chose React Three Fiber over Unity for seamless browser experience and superior UI integration

**Technologies**: React Three Fiber, Three.js, Zustand, Rapier.js, TypeScript, Performance Optimization

## 🚀 Getting Started

### Prerequisites
- [Bun](https://bun.sh/) (recommended) or Node.js
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/rknm-cell/personal-site.git
cd personal-site

# Install dependencies
bun install

# Start development server
bun run dev
```

### Available Scripts
- `bun run dev` - Start development server
- `bun run build` - Build for production
- `bun run start` - Start production server
- `bun run lint` - Run ESLint
- `bun run typecheck` - Run TypeScript type checking
- `bun run format:write` - Format code with Prettier
